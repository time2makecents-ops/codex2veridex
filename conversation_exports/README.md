# Conversation exports

Use this folder for thread summaries or transcripts that should travel with the repository.

## Naming

Use a date and short subject, for example:

`2026-09-15-james-cloutier-research.md`

## Workflow

1. Ask Codex to save the relevant thread or a specific portion here.
2. Review the file for personal, confidential, or account-sensitive information.
3. Commit and push the file when you want it available on another computer.
4. Pull the repository on the other computer.

Do not store passwords, API keys, OAuth tokens, private contact data, or other secrets in this folder. A saved file is only a copy; it does not automatically update when the conversation continues.
